I'm a **Machine Learning Engineer** focused on the engineering systems around machine learning: developing models, building inference services, packaging workloads, and understanding how models behave in production.

My main interests are:

- **ML systems:** reproducible experiments, model lifecycle, evaluation, and deployment.
- **MLOps & infrastructure:** containers, CI/CD, orchestration, observability, and cloud platforms.
- **Computer vision:** real-time detection, efficient inference, and edge-to-cloud workflows.
- **Backend engineering:** APIs and services that make ML capabilities usable and maintainable.

```text
Engineering principle:
A model is not a product until its data, evaluation, deployment,
runtime behavior, and failure modes are understood.
```
